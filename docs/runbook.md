# 運用確認メモ

- ALB のターゲットが unhealthy の場合、ECS タスク状態、`/health`、セキュリティグループの 8000 番と CloudWatch Logs を確認。
- タスク起動失敗時はイメージ URI・ECR アクセス・NAT 経路・実行ロールの Secrets Manager 権限を確認。
- DB 接続失敗時は RDS 状態、5432 番のセキュリティグループ、接続情報と TLS を確認。ログに認証情報を出さない。
- 409 は同一リソース・時刻の予約衝突。時刻は UTC に正規化される。
- 削除前に state と対象アカウントを確認。デモ DB は最終スナップショットなしで削除される。
